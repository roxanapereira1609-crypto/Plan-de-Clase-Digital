Plan de Clase Digital

Funciones de Excel de lo mas basico a lo mas avanzado

Bienvenidos a mi recurso educativo digital. Este espacio está diseñado para apoyar el aprendizaje de las funciones de Excel en estudiantes de nivel medio, comenzando con funciones básicas y avanzando progresivamente hacia funciones más complejas.

Mis objetivos como futura docente TIC

  • Crear recursos digitales que faciliten el aprendizaje.
  • Enseñar las funciones de Excel de manera práctica y sencilla.
  • Promover el uso de la tecnología como herramienta educativa.

Ruta de aprendizaje

Nivel básico

Aprende las funciones fundamentales de Excel.

  • SUMA
  • PROMEDIO
  • MAX
  • MIN

Nivel intermedio

Utiliza funciones para contar y trabajar con condiciones.

  • CONTAR
  • CONTARA
  • SI
  • CONTAR.SI

Nivel avanzado

Combina condiciones y realiza búsquedas de información.

  • SUMAR.SI
  • SI con Y / O
  • BUSCARV
  • BUSCARX
  • CONCATENAR
